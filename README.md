# My Zshrc Config

A beautiful and customized zsh configuration with an elegant prompt design.

## Overview

This repository contains my personal zsh configuration files featuring a custom prompt design that enhances your terminal experience with a clean, modern aesthetic.

## Features

- 🎨 **Custom Prompt Design** - A visually appealing and informative shell prompt
- ⚡ **Optimized Performance** - Fast and efficient configuration
- 🛠️ **Easy Customization** - Well-organized and documented configuration files
- 🎯 **User-Friendly** - Designed for productivity and comfort

## Installation

1. Clone this repository:
```bash
git clone https://github.com/Hilrein/my-zshrc-config.git
cd my-zshrc-config
```

2. Copy the configuration to your home directory:
```bash
cp .zshrc ~/.zshrc
```

3. Reload your shell configuration:
```bash
source ~/.zshrc
```

- Shell aliases and functions
